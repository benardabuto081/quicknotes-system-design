# QuickNotes System Design & API Client

## Description
QuickNotes is a full-stack system transition project designed to scale a note-taking platform from a browser-only prototype to a production-grade online service capable of supporting 1 million users. This repository contains both a functional front-end API client interfacing with mock endpoints and complete backend architectural specifications, data models, and API design documentation.
